LILY — JAPANESE FRIEND PWA

What it does
- WhatsApp-style Japanese chat
- Beginner-friendly offline Lily conversation engine
- Gentle correction for common beginner mistakes
- Japanese text-to-speech using your phone/browser
- Lesson 1 with 15 core words
- Vocabulary notebook
- Local progress and message counter
- Works without a backend
- Stores your data only on your device

Install on iPhone
1. Put this folder on a simple HTTPS website.
2. Open the website in Safari.
3. Tap the Share button.
4. Tap Add to Home Screen.
5. Name it Lily.
6. Open Lily from your Home Screen.

Important
A PWA service worker only installs correctly from HTTPS or localhost.
Opening index.html directly from the Files app will not install it as a full PWA.

Offline chat
This version uses a built-in local conversation engine, so it works without an API.
It is designed for beginner practice and does not have the full reasoning ability of ChatGPT.

Future upgrade
The app can later be connected to an AI backend for unrestricted conversations while keeping the same interface.
